Task:

You are tasked with reducing experimental protocols down to a set of parameters represented in JSON. Do this for every control and experiment.

Instructions:
Completeness: Ensure that appropriate controls for all experimental variables are included. If information is missing, use your knowledge to fill in the gaps based on the provided context.
Chemicals and Media: If a chemical needs to be dissolved in a solvent (e.g., DMSO), account for that in the baseline media.
Units: Always include units in all doses, concentrations, and times.
Experiment Combinations: Each unique combination of treatments and supplementations should be listed as its own experiment. Every condition and dose change counts as a new combination.
Consistency: Be consistent in naming and formatting throughout the JSON. Clearly differentiate between what is a supplementation and what is a treatment.
Logic Program: Include the selected logic/prolog program at the top of the JSON output under the "logic_program" field.
{
  "logic_program": <String>,
  "experiments": [
    {
  "experiment": <INT>,
  "baseline_media": <String>,
  "media_supplementation": <String>,
  "media_supplementation_doses": <String>,
  "treatment": <String>,
  "treatment_parameters": <String>,
  "sampling_time": <Float>,
  "type": <String>,
  "summary": <String>
}, ... ]}

If a category is not applicable, set it to null. OD is always monitored. "type" can be one of "control" (no supplementation or treatment), "supplementation control" (only supplement), "treatment control" (only treatment) or "experiment" (both). All of these should be present.
